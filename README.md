搜「便宜美国 VPS」的人，通常不是同一类需求。

一类是只要一台能跑起来的小鸡：装个面板、挂个探针、做落地节点，年付二三十美元，跑完就算了。另一类是要国内访问不卡，但预算又够不上搬瓦工那种价位。这两件事的答案，根本不在同一个价格带上。

所以先把账算清楚，再看 DMIT 这家常被拿来当对照的商家值不值得进你的候选名单。

## 先搞明白：美国 VPS 的「便宜」分三档

市场上公开报价大致是这么分的：

- **年付 $20–40**：1 核 1G、20G SSD、1TB 流量左右。典型是 RackNerd 的 1 核 1G / 20G / 3TB，$21.99/年。走的是普通国际线路，不针对中国优化。
- **月付 $5–12**：Vultr 1 核 1G / 25G / 1T 是 $5/月这个档位，按小时计费、随开随删；同价位还能买到带中国优化的入门款，但配置通常只有 1 核 1–2G。
- **月付 $15–50**：2 核 2G 到 4 核 4G，能正经跑 WordPress、小电商、API 服务。

跨过这三档往上看，价格就不再由 CPU 和内存决定了。同样 2 核 2G，走普通国际线路是一个价，走 CN2 GIA 是另一个价。

## 决定价格的是回程线路，不是配置

这一点值得单独说，因为「便宜」最大的陷阱就在这里。

- **普通国际线路**：到国内延迟大概 180–220ms，晚高峰丢包靠运气。
- **联通 9929 / 移动 CMIN2**：加价 30%–80%，晚高峰稳定性明显好转。
- **电信 CN2 GIA**：加价 50%–100%，到国内延迟能压到 150–170ms。

低价商家省成本，十有八九省在这条线上。看到一台 2 核 4G 卖 $8/月还宣称「三网优化」，先去看回程路由，别先看配置表。

## 便宜单里最容易踩的五个坑

**首年价不等于续费价。** 很多低价套餐只给首年折扣，第二年按原价续，长期成本直接翻倍。挑的时候优先找明确写着「续费同价」或者循环折扣的。

**「1Gbps 端口」后面还有一个月流量上限。** 端口速度是峰值，月流量才是你能用多久。超量之后有的降速到几十 Mbps 继续跑，有的直接停机。这两种体验差得很远，买之前必须看清超量策略。

**CPU 可能是几年前的 E5。** 同样 $4/月的价位，老架构 Xeon E5 跑 PHP 页面处理时间可能是新一代 AMD EPYC 的两倍。跑 WordPress 勉强够，跑 Node.js 实时服务就等着超时。

**IP 被墙和换 IP 政策。** 非中国优化线路的美国 VPS，IP 随时可能在某些地区不可达。能不能免费换、多久能换一次、有什么前置条件，这些写在条款里，不在宣传页上。

**超售。** 邻居把宿主机 IO 抢光，你的 2 核 4G 会表现得不如一台 1 核 1G。商家是否克制超售，比套餐参数更能决定长期体验。

## Pro / EB / T1 到底该选哪条

这是买 DMIT 时真正需要做的一次判断。三条线的差别不在配置，在回程路由。

**Pro（Premium）**：三网回程走 CN2 GIA（AS4809），去程电信是 CN2 GIA、联通和移动各走自己的骨干。面向中国大陆用户的站点、需要稳定低延迟的业务，选它。代价是价格最高。

**EB（Eyeball）**：三网回程走 CMIN2（AS58807），电信方向在 AS9929 和 AS58807 之间负载均衡。预算比 Pro 低一档，移动和联通用户的体验和 Pro 拉得很近，电信用户会略有差异。

**T1（Tier 1）**：GSL 国际线路，**没有中国大陆优化**。胜在流量多、带宽大、价格低，适合外贸站、备份、下载、边缘节点，或者你本来就有自建中转方案。

有个细节容易被忽略：LAX Pro 的 IPv6 实际走的是 AS4134，不是 CN2——因为 AS4809 境内段没有完成 IPv6 建设。所以别用 IPv6 去评测 Pro 的线路质量，测出来的是另一个东西。
